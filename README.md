# Proyecto-Integrador-Front

NextStep es una plataforma web diseñada para fortalecer el vínculo entre el instituto y sus egresados. A través de ella, la institución puede mantener a sus graduados informados sobre noticias relevantes, eventos, capacitaciones y otras actualizaciones importantes.

Además, permite la realización de encuestas para conocer la experiencia laboral de los egresados y recopilar datos sobre su inserción profesional. Esta información es clave para mejorar los programas educativos y fomentar una red activa de exalumnos.

La plataforma también facilita la visualización de estadísticas mediante gráficos, lo que permite al IFTS mostrar a futuros alumnos una proyección profesional basada en datos reales.

Asimismo, tanto la institución como sus egresados pueden publicar ofertas de trabajo accesibles para toda la comunidad. Los egresados, además, tienen la posibilidad de promocionar sus servicios, potenciando su desarrollo profesional.
